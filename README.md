# 🎮 GameZone — Play. Improve. Lead.

GameZone is an interactive gaming website built with React and Vite. It brings together fun mini-games where players can test their memory, improve reaction speed, guess numbers, and solve puzzles while competing for high scores.

## ✨ Features

- 🧠 **Memory Match** — Find matching emoji pairs and test your memory.
- 🔢 **Number Guess** — Guess the secret number using helpful hints.
- ⚡ **Reaction Speed** — Test your reflexes and reaction time.
- 🧩 **Puzzle Challenge** — Solve a sliding number puzzle in fewer moves.
- 👤 **Player Name** — Enter a player name to personalize your gaming experience.
- 🏆 **Top 10 Leaderboard** — View and compare game scores.
- 🔊 **Sound Effects** — Interactive audio feedback for game actions.
- 🎨 **Animations and Responsive UI** — Enjoy an engaging design across desktop and mobile devices.
- 🔄 **Restart Options** — Replay games and improve your performance.

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd game-zone
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually:

   `http://localhost:5173/`

## 📦 Build for Production

Run the following command to create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

GameZone can be deployed as a **Static Site** on platforms such as Render or Vercel.

For Render:

- **Build Command:** `npm install && npm run build`
- **Publish Directory:** `dist`

If using React Router, configure a rewrite rule so that application routes serve `index.html`.
